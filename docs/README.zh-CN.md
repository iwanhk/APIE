# 🥧 APIE — 中文简介

**AI Product Innovation Engine · 开放的产品创新知识库。**

一句话愿景：

> APIE 教会 AI 理解伟大的产品是如何被创造出来的——不是教它写 PRD，而是让它理解 Apple、Cursor、ChatGPT、TikTok、Robinhood 为什么成功，然后生成下一代产品。

核心哲学：

> 伟大的产品很少凭空诞生。它们来自发现伟大的模式（Patterns）、组合伟大的想法（Ideas）、解决真实用户问题（Problems）。

## 与 Awesome-LLM 的区别

Awesome 系列是**链接目录**，回答"去哪里读"。APIE 是**结构化知识库**，回答"Netflix 推荐循环的模式，如何迁移到投资产品"。

## APIE Brain

Retrieve → Reason → Compose → Evaluate → Innovate。不是"生成"，而是"组合"。详见 [innovation-engine/README.md](../innovation-engine/README.md)。

## 每日成长机制

每天产生 5 类内容：新产品追踪、模式挖掘、产品拆解（每天一个）、创新挑战（随机两个产品生成 20 个创新）、每周模式报告。详见 [DAILY-PIPELINE.md](DAILY-PIPELINE.md)。
