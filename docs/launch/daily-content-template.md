# 每日内容模板

配合 [DAILY-TASK.md](../DAILY-TASK.md) 使用。每个模板产出当天可分发的内容。

## 1. Teardown 线程（X/领英）

见 [x-thread.md](x-thread.md) 模板。核心结构：hook → 3 个反直觉事实 → 机制 → 3 条经验 → 教训 → CTA。

## 2. Pattern 卡片（每日一条）

```markdown
**Pattern of the Day: {名称}**
定义（一句话，无术语）
实例：{产品 A}、{产品 B}
何时用 / 何时别用
跨域候选：{域 A → 域 B}
```

## 3. 创新挑战（每日）

```markdown
# 创新挑战：{产品 A} × {产品 B}
抽象出的模式：{A 的核心模式}、{B 的核心模式}
20 个组合（每个标注 [模式组合]）
评分前 5（用户价值/可行性/护城河/时机/风险）
胜出概念：目标用户 / 核心循环 / 北极星指标 / pattern stack
```

## 4. Weekly Pattern Report（周五）

```markdown
# Weekly Pattern Report — W{周数}（{日期范围}）
## 本周新产品（值得研究）
## 新模式 / 模式变化
## 拆解回顾（Day N–M）
## 下周预告
```

## 5. 分享时刻（每周一条）

把本周最好的 pattern 卡片做成图（可选），配 30 秒文字说明，发 X + LinkedIn + 公众号/即刻。
