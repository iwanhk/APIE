## 基本信息

## Description

```text
APIE is an open, machine-readable knowledge base of product innovation:

• Unified schemas — every teardown, pattern, feature, and cross-domain transfer
  follows one of 5 open standards, so AI can index the entire library without cleaning
• Cross-domain transfers — the part nobody else builds: Netflix's recommendation
  loop transplanted into investment products, TikTok's feed into CRM
• Machine-native — everything compiles into datasets/*.json for any agent to query
• A daily pipeline — one product teardown per day, pattern mining, innovation
  challenges, and weekly pattern reports

Today: Cursor, Lovable, Robinhood teardowns; 5 patterns; 6 features; 4 UX flows.
Free, MIT-licensed, and it grows every single day.
```

## First comment

```text
I built APIE because I kept seeing the same failure: AI writes great PRDs but has no
idea WHY a product worked. So I started tearing down one product per day and encoding
the patterns into a structured, open knowledge base.

Day 001 Cursor, Day 002 Lovable, Day 003 Robinhood — 365 days to go. Contributors
welcome: every teardown, pattern, or cross-domain transfer follows the schema and is
instantly indexable.
```
