# Business Models

Pricing and business-model knowledge for product analysis. Each model gets a file when it has enough evidence; until then, the taxonomy below is the index.

## AI-Era Taxonomy

| Model | Mechanism | Canonical example |
| --- | --- | --- |
| Per-seat subscription | price per user per month | Cursor, Linear |
| Usage-based / credits | price per token/request/compute | OpenAI API, Replit AI |
| Hybrid (seat + usage) | base seat, metered AI requests | Cursor, GitHub Copilot |
| Freemium | free tier as distribution, paid for limits | ChatGPT, Figma |
| Open source + cloud | free software, paid hosting | Supabase, GitLab |
| Marketplace | take rate on third-party supply | Shopify, Airbnb |
| Enterprise contract | custom deal for large buyers | OpenAI Enterprise, Harvey |
| Consumption + annual commit | reserved capacity with discount | cloud providers |
| Ad-supported | attention monetized | TikTok, Google |
| Co-GP with carry split | joint management, shared economics | [CoGP-Carry-Split.md](CoGP-Carry-Split.md) |

## What to Document Per Model

When a model earns a file: Definition · Unit economics (LTV, CAC, gross margin, expansion) · Pricing design · Growth mechanics · Risks · Example products.

**Sign convention note (financial accuracy rule):** all money terms in this repository use standard accounting sign conventions — revenue is positive, costs are negative, cash outflows are negative. Any spreadsheet-style analysis must reconcile to zero.
