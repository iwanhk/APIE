# Community

APIE is only useful if it keeps growing. Here is how to plug in.

## Ways to Participate

- **Submit a teardown** — one sourced product analysis ([template](../products/_TEMPLATE.md))
- **Submit a pattern** — one repeatable mechanism ([template](../patterns/_TEMPLATE.md))
- **Run an Innovation Challenge** — pick two products, generate 20 combinations
- **Translate** — schemas and README into your language
- **Review** — facts rot fast; flag stale numbers with a PR or issue
- **Adopt the standard** — use APIE schemas in your own knowledge base; tell us how

## Governance (as of v0.1)

- Maintainers review PRs against the [contributing rules](../CONTRIBUTING.md)
- Schema changes require an RFC-style issue and a 7-day comment period
- Disagreements about facts are resolved by sources, not opinions
- The daily pipeline is community-run until automation lands (Phase 3)

## Communication

- GitHub Issues — bugs, missing facts, proposals
- GitHub Discussions — pattern debates, innovation challenges
- Weekly Pattern Report — the community's shared synthesis ([docs/reports/](../docs/))
