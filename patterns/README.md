# Pattern Library

The core of APIE. A pattern is a **repeatable mechanism** — a solution structure that recurs across products and transfers across domains. Schema: [APIE Pattern Schema v1](../docs/APIE-Pattern-Schema-v1.md).

## Pattern Areas (backlog)

## Rules

1. Every pattern has ≥2 product instances with the *mechanism*, not just the name.
2. Every pattern names when **not** to use it.
3. Established patterns get cross-domain transfer candidates; emerging patterns get a watching brief.
4. New patterns update [PATTERNS.md](../PATTERNS.md).

Start from [patterns/_TEMPLATE.md](_TEMPLATE.md).
