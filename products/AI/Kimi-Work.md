# Kimi Work

## Overview

Kimi Work is Moonshot AI's desktop "working agent" — a local agent for macOS (Apple Silicon) and Windows that turns natural-language goals into executed work: task decomposition, parallel agent clusters, browser automation, file/folder handling, and delivery of documents, spreadsheets and PPTs (as of 2026-06, [IT之家](https://m.ithome.com/html/959547.htm)). Its one-sentence mechanism: **a local agent runtime built on Kimi Code plus an agent swarm orchestrator, so capability is measured in parallel autonomous agents (up to 300) and in durable session artifacts, not in chat replies.** It extends Moonshot's consumer chat assistant (Kimi) into "from Coding Agent to Working Agent" territory, aimed at knowledge workers in research, finance, law and general office work.

## Target User

Primary user is the **knowledge worker** — researcher, analyst, lawyer, office professional — who wants agentic work delivered on their own machine rather than in a browser chat (IT之家 positioning, 2026-06). Users and payers are the same person in consumer tiers; in China the competitive set is other work agents (Tencent WorkBuddy, ByteDance TreeWork, Alibaba office agents), with Kimi positioning on the entrepreneurial/startup side ([东吴证券纪要 via 发现报告](https://www.fxbaogao.com/detail/5561352), as of 2026-07-25). The swarm mode (300 sub-agents) is explicitly a paid feature, so heavy agent users pay more ([今日头条](https://m.toutiao.com/article/7647828030538187270/), 2026-06-04).

## Business

Freemium subscription: free Adagio tier with limited credits; paid tiers Moderato $19/mo (K2.6, Deep Research, Kimi Code), Allegretto $39/mo (limited agent swarms), Allegro $99/mo, Vivace $199/mo (full agent swarm / 300 sub-agents) (as of 2026-06-11, [KuCoin](https://www.kucoin.com/news/flash/moonshot-ai-launches-desktop-agent-product-kimi-work-with-local-execution-and-300-sub-agents); [USECarly](https://www.usecarly.com/blog/what-is-kimi-work/), 2026-07-19). Distribution is the existing Kimi app surface (desktop client) plus kimi.com downloads — no separate marketplace. Moonshot's revenue is not public; reported valuation ~$30B and the K3 sell-out signal investor appetite for agent-grade models rather than chat MAU ([Kchuhai](https://www.kchuhai.com/report/view-67260.html), 2026-06-24; [TheAIToolsBox](https://theaitoolsbox.com/blog/kimi-k3-moonshot-open-weight-model-sold-out/), 2026-07-27).

## Growth

The headline loop is **agent capability as marketing**: "300 sub-agents running in parallel" and "13-hour continuous coding, 4,000+ tool calls" became the shareable proof points that moved Kimi Work onto tech-media radars at launch (2026-06). The second loop is **model release → app MAU**: Kimi K3's open-weight launch re-energized the brand, reversing MAU decline (+15.53% to 26.21M, 2026-08-02). The third loop is **dogfooding as credibility**: Kimi Work being 92% AI-written by Kimi Code is itself a growth narrative for the coding-agent market. A fourth, structural loop is the **local-agent data moat**: sessions, files and workflow history accumulate on the user's machine, making the assistant more useful over time and raising switching cost.

## UX

Entry experience: install the desktop client, describe a goal in natural language — no terminal, no environment setup (IT之家, 2026-06). Core loop: user states an objective → Kimi Work decomposes it, spawns parallel sub-agents, calls tools, drives the browser via WebBridge, creates and organizes folders, and delivers finished artifacts (documents, spreadsheets, PPT) ([Moneycontrol](https://www.moneycontrol.com/news/trends/moonshot-ai-launches-kimi-work-a-desktop-ai-that-can-run-300-agents-at-once-13945970.html), 2026-06-09). Scheduling is a first-class UX: a Cron engine runs tasks daily/hourly/on condition, with "Keep Computer Awake" for overnight jobs ([Yahoo Tech](https://tech.yahoo.com/ai/meta-ai/articles/moonshot-ais-kimi-brings-300-184057169.html), 2026-06-11). The 2026-08 feedback-report finding shows the session store is part of the UX surface too — raw sessions ride along with user feedback, currently without disclosure ([RuntimeWire](https://runtimewire.com/article/scoop-kimi-work-secretly-attaches-raw-records-from-five-recent-agent-sessions-to), 2026-08-15).

Model stack: Kimi K2.6 at launch (June 2026), with Kimi K3 (open-weight, sold-out launch) arriving July 2026 ([KuCoin](https://www.kucoin.com/news/flash/moonshot-ai-launches-desktop-agent-product-kimi-work-with-local-execution-and-300-sub-agents), 2026-06-11; [TheAIToolsBox](https://theaitoolsbox.com/blog/kimi-k3-moonshot-open-weight-model-sold-out/), 2026-07-27). The agentic core is Kimi Code, with a **swarm orchestrator** that autonomously creates up to 300 sub-agents proportional to task complexity; reported endurance of 13 hours of uninterrupted coding and 4,000+ autonomous tool calls ([iHeima](http://www.iheima.com/article-398122.html), 2026-06-03). Skills system: installable/usable skills plus professional databases for finance, research and law inherited from online Kimi Agent ([IT之家](https://m.ithome.com/html/959547.htm)). Evals: `Unknown` — no public benchmark suite for Kimi Work itself as of 2026-08. Data flywheel: local session history + scheduled-job results compound per user, though the unattached feedback-session upload shows flywheel data also flows to the vendor ([RuntimeWire](https://runtimewire.com/article/scoop-kimi-work-secretly-attaches-raw-records-from-five-recent-agent-sessions-to), 2026-08-15).

## Architecture

Product-level architecture (2026-06 reports, [KuCoin](https://www.kucoin.com/news/flash/moonshot-ai-launches-desktop-agent-product-kimi-work-with-local-execution-and-300-sub-agents); [Yahoo Tech](https://tech.yahoo.com/ai/meta-ai/articles/moonshot-ais-kimi-brings-300-184057169.html)): a **desktop client** (macOS Apple Silicon, Windows) hosting the local agent runtime; **Kimi Code kernel** for agentic coding/tool execution; a **swarm orchestrator** for parallel sub-agent creation and coordination; **Kimi WebBridge** browser extension bridging to web pages (form filling, data extraction); **local file system access** (folder creation/organization, PDF manipulation); **background Python execution**; a **Cron scheduler** with conditional triggers and wake-keep; and **deliverable generators** (documents, spreadsheets, PPT). The **session store** records tool calls and decisions locally and is also attached to feedback reports — the artifact layer that today's pattern files ([Session-as-Artifact](../../patterns/Session-as-Artifact.md)) builds on.

## Patterns

- [Session-as-Artifact](../../patterns/Session-as-Artifact.md) — Kimi Work's raw agent sessions are packaged and attached to feedback reports (found 2026-08-15); the session becomes a reviewable, transportable artifact rather than disposable state.
- [Parallel Agent Orchestration](../../patterns/Parallel-Agent-Orchestration.md) — the 300-sub-agent swarm is the canonical industrial instance: task complexity determines cluster size, with parallel tool use across browser, Python and files.
- [Capability-Gated Release](../../patterns/Capability-Gated-Release.md) — swarm/cluster mode is reserved for higher paid tiers (Allegretto+), so the most impressive demo capability is also the monetization gate ([KuCoin](https://www.kucoin.com/news/flash/moonshot-ai-launches-desktop-agent-product-kimi-work-with-local-execution-and-300-sub-agents), 2026-06-11).
- Emerging candidate (watching brief): **Ambient Work Memory on desktop** — local files, sessions and scheduled jobs accumulate into a machine-resident memory; adjacent to OpenAI Computer History and Windsurf Cascade Memories, worth filing when a second shipping instance appears with explicit memory semantics.

## Lessons

Copy: make the impressive capability the paid tier (swarm as the demo AND the price gate); dogfood your own tool publicly (92% AI-written client builds trust and market); let scheduling turn an agent into a service (Cron + "keep awake" = the agent becomes infrastructure, not a chat); local execution creates a data moat that hosted chat can't replicate. Avoid: shipping session capture without disclosure — the 2026-08 feedback-report finding converted a feature into a trust liability within days ([RuntimeWire](https://runtimewire.com/article/scoop-kimi-work-secretly-attaches-raw-records-from-five-recent-agent-sessions-to)); and over-relying on model-launch spikes to carry MAU (the June 9.02M trough shows chat-assistant MAU is not the same metric as agent utility).

## Innovation

Kimi Work industrialized the **local working agent**: natural-language goals → decomposed parallel swarm → browser/file/tool execution → deliverable artifacts, all on the user's machine, with scheduling as a first-class primitive. It is also the first mainstream instance of **raw agent sessions as attachable evidence** — a mechanism that cuts both ways (debugging/audit upside, privacy downside). Natural next transfers: institutional research desks (swarm + session evidence for audit-ready memos — see [Session-as-Artifact → Investment Decision Audits](../../cross-domain/Session-as-Artifact-to-Investment-Decision-Audits.md)), regulated professions where session artifacts can document advice process, and personal-finance automation where the Cron engine turns the desktop agent into a recurring financial operator.
