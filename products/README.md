## Rules

1. One product, one file. Category = primary market.
2. Every teardown is **sourced** and dated. Unknown facts are written as `Unknown`, never guessed.
3. Every teardown links at least one pattern in [patterns/](../patterns/README.md) — otherwise it is a dead end.
4. New teardowns update [PRODUCTS.md](../PRODUCTS.md) and are added to the daily reverse-engineering queue.

Start from [products/_TEMPLATE.md](_TEMPLATE.md).
