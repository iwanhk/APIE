# Fund Deep-Dive

## Goal

用户把一只基金看懂到"能用自己的话讲清它的风险和代价"的程度，然后**自己**决定——AI 全程只教育、不下结论。

## Entry Points

- [Fund Compare](../features/Fund-Compare.md)（对比后进入单只深潜）
- Fund Passport 的"深入"按钮
- 持仓雷达事件（持有的基金有变动）
- 教育路径的深潜课程

## Steps

1. **一句话** — 这只基金是什么（白话，30 秒可读）
2. **五段 Passport** — 是什么 / 谁在管 / 收费 / 风险 / 业绩（每项带来源和 as-of 日期）
3. **问 AI** — 任意问题，答案只基于已入库文件并带引用
4. **情景模拟** — "如果跌 20%/50%，你的投资会怎样"——把风险翻译成用户自己的数字，不下结论
5. **自我检查** — "我的目标 vs 这只基金的性质"对照卡（教育工具，不是匹配评分）
6. **决定** — 用户自行决定；选择"再想想"也完全正常

## Decision Points & Failure Paths

- 用户问"我该买吗" → 中性模板回应："我不能替你决定。你需要判断的是：这只基金的风险你能否承受、锁定期你是否接受。" 然后回到情景模拟
- 用户试图跳过阅读直接入金 → 提示"先看 3 分钟风险页"，不阻断但记录
- 数据缺失（如业绩无独立审计）→ 明示"无来源"，绝不补白
- 用户反复问同一风险 → 说明没看懂，降速重讲（教育优先于转化）

## Success Criteria

复述测试通过（用户用自己的话讲清风险与代价）+ 用户明确做出自己的决定（买 / 不买 / 再想想）。

## Metrics

深潜完成率、复述测试通过率、AI 越界率（给出建议/排名/收益承诺，必须为 0）、深潜→入金的时间间隔（教育后入金是健康信号，秒入是警示信号）。
